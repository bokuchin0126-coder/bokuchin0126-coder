# 井之上 勇人

Webエンジニアへの転職を目指しています。

React / TypeScriptを中心に学習し、Webアプリケーションの個人開発に取り組んでいます。
現在は、実際の開発業務に携わることを目標に、個人開発を通して技術力を高めています。

## スキル

- TypeScript
- React
- Vite
- Supabase
- PostgreSQL
- React Router
- dnd-kit
- Vitest

## プロジェクト

### Study Planner

日・週・月・長期の学習計画とタスクを管理するWebアプリです。

React + TypeScript + Supabaseを使用し、
認証・データベース・テスト・レスポンシブ対応・本番環境へのデプロイまで実装しています。

[Repository](https://github.com/bokuchin0126-coder/study-planner)  
[Demo](https://study-planner-mu-eight.vercel.app/)

## 学習内容

React / TypeScriptを中心にWebアプリケーションを開発しながら、
認証・データベース・API・テストなど、Web開発に必要な知識を実践的に学んでいます。

分からないことを調べて実装するだけでなく、
実際に動かして問題点を確認し、改善することを意識しています。

## キャリア

Webエンジニアとして実際の開発業務に携わり、
実務を通して技術力を高めていきたいと考えています。

将来的には、フロントエンドだけでなく、
バックエンドやデータベースも含めてWebアプリケーション全体を理解できるエンジニアを目指しています。
